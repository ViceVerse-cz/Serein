# Discord-style message toolbar evidence

All application images show Serein's synthetic `--demo` workspace, never an authenticated or live
Discord session. The English Discord reference images supplied with the request are design targets,
not Serein evidence and are not committed here.

## Baseline

- Source revision: `21f8870b3849f24f9b0fb0bb17b9e3e272e2b93a` (`origin/main` when the task began).
- `before-window.png`: native X11 debug build with `--demo --demo-chat`, dark appearance, 2240×1520
  pixels, Czech UI, isolated synthetic data.
- `before.png` and `before-shift.png`: native crops of the same offline synthetic workspace supplied
  by the user while checking the existing normal/Shift hover states. They show another author's
  message, so Edit/Delete are correctly absent. No credentials or private conversation are present.
- Latest release audit: `v1.0.0-nightly.20261107.81` at
  `a3ae6385e84d1ad58c5ac04c58bfd026fd2d4352`. None of the nine following commits changed this
  hover layout. Open PRs #879 and #928–#931 were reviewed to avoid duplicating their work.

## After

`after.png`, `after-shift.png` and `after-window.png` were generated by the actual egui/wgpu native
`profile_preview` renderer at 1120×760 logical pixels (2240×1520 framebuffer pixels), dark appearance,
Czech UI and the same `chat_demo_state()` fixture. RawInput events inject a pointer over the
conversation and either normal or Shift modifiers, so no OS input injection, focus hacks, credentials
or live session is involved. The `--close-settings` option distinguishes the timeline from the Chat
settings page; the identical fixture source is copied into the baseline worktree for measurements.

Reproduce from the repository root:

```sh
cargo run --locked -p serein --features demo --example profile_preview -- \
  --demo --toolbar-hover=normal --width=1120 --height=760 \
  --output=docs/pr-evidence/discord-message-toolbar/after.png

cargo run --locked -p serein --features demo --example profile_preview -- \
  --demo --toolbar-hover=shift --width=1120 --height=760 \
  --output=docs/pr-evidence/discord-message-toolbar/after-shift.png

cargo run --locked -p serein --features demo --example profile_preview -- \
  --demo --close-settings --page=chat --width=1120 --height=760 \
  --output=docs/pr-evidence/discord-message-toolbar/after-window.png
```

The images were inspected after generation. Normal hover shows quick reactions, Translate, Add
Reaction, Edit, Reply and More. Shift shows Copy ID/Link, Reply, Translate, Add Reaction, Edit,
Forward and a red Delete, with no quick reactions or More. In this fixture optional Pin/Mark Unread
are unavailable, and Bookmark is deliberately absent because Serein has no bookmark store.

`after-shift-light.png` repeats the Shift capture in light mode and was inspected for contrast and
clipping. It uses the identical native fixture. No screenshot shows outside-window or account data.

Headless tests separately drive real egui hover/Shift/click and Shift+F10 events, assert actions and
copy payloads, and verify painted menu content. The images are UI evidence only; they do not prove
live Discord interoperability.
