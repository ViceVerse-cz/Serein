# Media privacy

Masks every image, GIF and inline video in chat until the pointer rests on it. The
composer button beside the GIF trigger toggles masking; Settings > Extensions >
Media privacy configures hover reveal, blur strength, mask opacity and a blur, black,
grey, white or custom solid effect.

The host draws the mask from bounded coarse copies of media it already decoded. The
plugin receives no message content, media URLs or pixels.
