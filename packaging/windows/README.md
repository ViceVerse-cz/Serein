System notifications require a Start Menu shortcut carrying Serein's own AppUserModelID (`org.serein.desktop`). After extracting the package to its final folder, explicitly run `powershell -File .\install-notifications.ps1` from that folder (the script must be beside `serein.exe`). It creates only the current user's `Serein.lnk`, without administrator rights or autostart, and refuses to overwrite an existing shortcut. `powershell -File .\install-notifications.ps1 -Remove` removes that shortcut before moving/uninstalling the package. Normal builds and startup never run this script automatically. Follow local script-signing policy; no execution-policy bypass is required or bundled.

Enable system notifications separately in Serein for each session and allow them in Windows Settings. Generic alerts hide sender/channel/message content; logout/disable requests removal of Serein's outstanding notification history through WinRT, without claiming forensic erasure. Native activation/deep links are not implemented. ## Windows Installer & Setup

Serein supports both portable zip extraction and a per-user Windows installer:
- **NSIS Installer**: `packaging/windows/installer.nsi` builds `dist-installer/serein-<version>-setup.exe` via `makensis`. It installs per-user to `%LOCALAPPDATA%\Programs\Serein` (`RequestExecutionLevel user`) without requiring administrator elevation. This preserves full user write permissions for the in-app autoupdater.
- **PowerShell Setup**: `packaging/windows/setup.ps1` provides a zero-dependency installer/uninstaller script (`powershell -File .\setup.ps1` to install, `powershell -File .\setup.ps1 -Uninstall` to remove).
- **Autoupdate Compatibility**: Both installers register Serein in `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Serein`. When Serein autoupdates, the update helper automatically synchronizes `DisplayVersion` in the registry upon file replacement, keeping Windows Settings and Installed Apps accurate. The release zip packages remain strictly decoupled from the installer executable, preventing allowlist check failures during in-app update extraction.
